# Hurdle Club

A small Java console hurdles race. Type commands to run and jump over each hurdle. The track redraws in place instead of scrolling through the terminal.

## Run

Open the VS Code integrated terminal in this folder and run:

```powershell
javac HurdlesRace.java
java HurdlesRace
```

## Controls

- Press `Enter` to start the race and to run forward one turn.
- Type `j` and press `Enter` to jump.
- Type `q` and press `Enter` to quit the race.
- Clear 10 hurdles to finish. The track is drawn using plain text characters.
